### Human verification highlights

- **Contract truthfulness** — every TypeScript model and every integration-map row was diffed against the backend's OpenAPI spec and live responses, not accepted from memory.
- **Security boundary respected** — role guards / hidden buttons were treated as UI only; the backend middleware was re-tested (401/403/409/422) to confirm it enforces what the UI suggests.
- **End-to-end proof** — the app was compiled (`tsc -b` + `vite build`) and the full routed application exercised in jsdom against the *real* API base URL via MSW, plus live curl checks of student search, academic record, roster, and error codes against the running Laravel server.
- **AI output owned** — generated code was reviewed line-by-line; several typing, cleanup, and API-contract issues found during review were fixed manually (see Review columns).
